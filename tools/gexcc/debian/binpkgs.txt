# SRCPKG BINPKG GLOB... : how mkdebs.py splits a staging tree into Debian's
# binary packages. A file goes to the first matching line; BINPKG `-` drops
# it. A source package with no lines becomes one package of its own name.
# `depends BINPKG DEPENDS...` adds a Depends field (Debian's data packages
# ours use: architecture-independent content, Multi-Arch: foreign);
# `predepends BINPKG ...` a Pre-Depends field; `arch BINPKG ARCH` labels a
# package with another architecture (dpkg and apt: arm64, docs/gexcc.md
# §6.1a). The rest of a depends/predepends line is one relation.
